# Data Visualization Project

This is the source code of the this project about data visualization. 
The idea of the project is to build a dashboard to interact with the current available player for this current year *Fantacalcio*.
The game mode is *mantra* and in this mode I have to field 11 players according to their role.

The overall goal is to learn new concepts and stragies and have a deeper and better understanding of the technology used in the project.
For this project I prefer to use Python for the scripting and ETL and a SQL database to store historic perfomance data about players.
